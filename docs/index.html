VIDEO

A demonstration of the game running on a Commodore Plus/4 — also on YouTube.

This page launches a Commodore Plus/4 emulator in your browser. It boots VICE (xplus4) through EmulatorJS and loads the real program straight from the main branch of the repository — the same file you would put on a disk.

Give it up to two minutes. A white screen with a pink border means it is still loading; that is the Plus/4 sitting at its own boot screen while the program comes in. You will know it is ready when the screen fills with animation and the music starts.

WHAT THIS IS

A compiled port of a game that already existed in Commodore BASIC 3.5. The BASIC edition took 24 seconds to draw the board and 2.8 seconds to work out which moves are legal. Rewritten in C and 6502 assembly, the same work takes milliseconds — and the recovered time was spent on things the BASIC edition had ruled out: motion tweening, a real dice tumble, and music playing from a raster interrupt while the game runs.

PrimitiveBASIC 3.5CompiledSpeedup
draw the board23 960 ms123.4 ms194×
paint one 4×4 square594 ms2.05 ms290×
refresh both token rows1 826 ms7.48 ms244×
find the legal moves2 785 ms4.83 ms577×

Measured on the machine, both editions against the same PAL jiffy clock. It has also been run on real restored hardware, loaded from an SD2IEC.
