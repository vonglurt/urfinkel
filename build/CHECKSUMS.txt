UR FINKEL - checksums for the published binaries
================================================

Build date 2026-08-10, as stamped into the program and drawn on its menu.
Generated by tools/checksums.sh; do not edit by hand.

These two files are what https://github.com/vonglurt/urfinkel
offers as downloads. The names below are bare, so save this file into
the same folder as the download, then run either of:

    shasum -a 256 -c CHECKSUMS.txt
    md5sum -c CHECKSUMS.txt

Each tool warns that the other's lines are improperly formatted and
skips them. That is expected - both algorithms share this one file -
and the lines it does read are still checked and still reported.
